# HH Pilot — Security Specification

## Baseline

- Не хранить секреты в репозитории.
- Использовать `.env` для локальных секретов.
- Не публиковать API keys, access tokens или credentials.
- Валидировать данные на серверной стороне.
- Не доверять данным, поступающим от клиента.
- Для production включать безопасные cookie и HTTPS.
- Перед релизом проверять зависимости и конфигурацию.

Этот документ является базовым и должен расширяться по мере появления реальных функций приложения.
